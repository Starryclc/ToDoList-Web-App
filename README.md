# TO DO List

一个纯前端、浏览器本地运行的 To-do-list 应用，参考 Microsoft To Do 的交互思路，支持普通任务、循环任务、任务分组、步骤拆解、本周速览、我的一天、重要标记、备忘录、搜索、归档、备份、恢复等功能。

## 产品简介

本项目适合个人任务管理场景、不方便安装可执行文件的环境。强调以下目标：

- 打开即用：无需后端、无需登录
- 结构清晰：系统清单 + 自定义清单
- 信息完整：任务标题、备注、步骤、截止日期、循环任务、创建/完成时间，以及独立备忘录
- 长期可用：支持备份恢复与按年归档（导出 CSV）

## 核心功能

### 1. 清单体系

- 系统清单：
  - `我的一天`
  - `重要`
  - `本周速览`
  - `全部任务`
  - `备忘录`
- 自定义清单：
  - 支持新建、重命名、删除、拖拽排序

### 2. 任务管理

- 新增任务：标题、步骤、截止日期/时间、重复、备注
- 编辑任务：支持修改任务全部字段
- 完成状态切换：支持取消完成
- 重要标记：星标切换
- 添加到我的一天：太阳图标切换
- 快捷设置截止日期：今天、明天、本周、下周
- 快捷设置具体时间：中午前（12:00）、下班前（17:30）

### 3. 步骤子任务

- 支持为任务添加多个步骤
- 步骤可独立勾选、删除
- 主任务完成时，步骤同步完成
- 主任务取消完成时，步骤重置为未完成

### 4. 截止日期与超期规则

- 日期与具体时间可以分别设置；未选择日期时不会单独保存具体时间
- 自定义时间选择器支持 24 小时制、以 5 分钟为间隔选择，双击小时可直接选择整点
- 日期或时间可通过清除按钮、Backspace 或 Delete 清除；清除日期时会同时清除具体时间
- 未完成任务：按当前时间动态判断是否超期
- 已完成任务：按“完成当时”判断是否超期
- 对于仅日期（无具体时间）的任务：当天完成不判定超期
- 超期任务截止日期会标红显示；对于仅日期（无具体时间）的任务，虽当天不判定为超期，仍会标红以示提醒

### 5. 循环任务

- 支持每天/每周/每月/每季重复
- 当期任务完成后自动创建下一期任务
- 下一期任务步骤自动重置为未完成
- 月末日期会对齐到目标月份最后一天（例如 1 月 31 日的下一月为 2 月末）

### 6. 我的一天

- 支持通过太阳图标手动添加或移除任务
- 截止日期为当天的未完成任务会自动加入“我的一天”
- 编辑自动加入的任务并将截止日期改为非当天时，会同步从“我的一天”移除
- 手动加入“我的一天”的任务不会因编辑截止日期而被自动移除
- 循环任务生成下一期时，若下一期当天到期，会自动加入“我的一天”

### 7. 备忘录

- 独立的“备忘录”系统入口，与任务清单分开管理
- 支持新建、编辑、删除备忘录，输入内容时自动保存并记录更新时间
- 备忘录按最近更新时间倒序排列
- 点击卡片可继续编辑，编辑窗口支持放大和还原
- 标题输入完成后按 Enter，可直接切换到正文输入框
- 支持按标题和正文搜索，并高亮匹配关键词

### 8. 搜索与展示

- 任务视图支持检索任务标题、备注、步骤内容
- 备忘录视图支持检索备忘录标题和正文
- 搜索结果支持关键词高亮
- 支持“展示详情 / 隐藏详情”
- 支持“展示已完成 / 隐藏已完成”

### 9. 排序能力

- 排序项：
  - 默认排序
  - 按截止日期升序/降序
  - 按创建日期升序/降序
- 当前策略：
  - 未完成任务：
    - 默认排序：重要任务优先，其次按截止日期升序，最后按创建时间倒序兜底
    - 非默认排序：重要任务不再固定置顶，按所选规则参与排序
  - 已完成任务：固定按完成时间倒序（最新完成在最上）

### 10. 本周速览

- 汇总两类任务（周一到周日）：
  - 本周已完成任务（按完成时间）
  - 本周到期但未完成任务（按截止时间）
- 标题下展示本周日期范围
- 不允许手动直接添加到本周速览

### 11. 快捷键与输入交互

- 在任务标题输入框按 Enter 可直接添加任务
- 在展开的新增任务区域按 Shift+Enter 可添加任务
- 在步骤输入框按 Enter 可添加步骤
- 时间选择器可通过 Enter、空格或方向键下打开，通过 Escape 关闭
- 在备忘录标题输入框按 Enter 可切换到正文输入框
- 中文输入法正在组词时，Enter 不会误触发上述提交或跳转操作

### 12. 数据能力（备份/恢复/归档）

- `备份`：导出当前全部任务、清单和备忘录数据（JSON）
- `恢复`：导入 JSON 数据，并兼容旧版本缺失字段
- `归档`：
  - 输入“完成年份”筛选已完成任务
  - 导出为 CSV
  - 可选择导出后从当前任务中移除以减轻存储负担
- 归档 CSV 列顺序：
  - 标题、步骤、备注、所属清单、截止日期、创建时间、完成时间

## 数据存储说明

- 主存储：`IndexedDB`
- 兼容回退：`localStorage`
- 旧版本数据会自动迁移
- 数据为浏览器本地站点数据，清理站点数据后会丢失，建议定期“备份”或“归档”

## 项目结构

- `index.html`：页面结构
- `assets/css/todo-app.css`：样式文件
- `assets/js/todo-app.js`：业务逻辑与数据处理
- `assets/js/recurrence.js`：循环任务日期计算

## 使用方式

1. 直接用浏览器打开 `index.html`，固定保存路径后浏览器收藏即可直接通过浏览器打开
2. 开始管理任务
3. 建议定期点击“备份”导出 JSON
4. 每年或按需使用“归档”导出 CSV 并清理历史完成任务
